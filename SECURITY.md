# Security Policy / Политика безопасности / Xavfsizlik siyosati

## Reporting a Vulnerability / Сообщение о уязвимости

Если нашли баг или уязвимость — создайте **private issue** или напишите:
- Email: hackerspace.tashkent@gmail.com
- Telegram admin: свой username

**Не создавайте public issues** для уязвимостей — сначала сообщите нам.

## Response / Время ответа
- Low: 7 дней
- Medium: 3 дня
- High: 24 часа

## Scope / Что входит
- Токены, пароли, секреты в коде
- XSS, injection в веб-части
- Неправильная обработка данных пользователей
- Фишинг, спам в коммуникациях

## Rules / Правила
- Не используйте найденные уязвимости в целях
- Не публикуйте до исправления
- Помогайте с исправлением
