Добро пожаловать в официальное комьюнити **Hackerspace Tashkent** — пространство для обмена знаниями, проектами и событий в сфере технологий, электроники и open-source.

## 📌 О нас

Мы — сообщество энтузиастов из Ташкента и Узбекистана, которые:

- 🔧 **Создают железо** — Arduino, ESP32, Raspberry Pi, FPGA, встраиваемые системы
- 💻 **Пишут код** — веб, мобильные приложения, десктоп, DevOps
- 🤖 **Экспериментируем** — робототехника, IoT, AI/ML, компьютерное зрение
- 📚 **Делимся опытом** — воркшопы, митапы, хакатоны, совместные проекты

## 🎯 Чем занимаемся

- **Воркшопы и митапы** — регулярные встречи онлайн и оффлайн
- **Совместные проекты** — от идеи до прототипа и релиза
- **Менторство** — помощь новичкам в старте
- **Open-source** — публикуем код, схемы, документацию
- **Hardware lab** — работаем с железом, датчиками, платами

## 🛠 Как мы учимся (практика + теория)

Мы используем **GitHub Codespaces** для совместной работы прямо в браузере — никаких установок, никаких локальных настроек. Учитель проводит созвоны, смотрит файлы через веб-интерфейс Codespaces и проверяет прогресс ученика.

### Структура обучения (60% практика, 40% теория)

| Тип | Процент | Описание |
|-----|---------|----------|
| **Практика** | 60% | Hands-on задачи в Codespaces: установка пакетов, скриптинг, Git, мониторинг |
| **Теория** | 40% | Объяснения "почему" перед каждым заданием |

### Основные практические задачи

- **Навигация по файловой системе** — права доступа, rwx, владельцы
- **Установка пакетов** — apt/yum, базовый пакетный менеджер
- **Системный мониторинг** — `df`, `top`, `ps`, диагностика ресурсов
- **Bash скриптинг** — автоматизация, `#!/bin/bash`, исполняемые файлы
- **Git workflow** — инициализация, ветки, коммиты, push
- *(Опционально)* **Docker** — контейнеры для изоляции приложений

### Что вы получите после участия

- ✅ Уверенность в работе с Linux-окружением
- ✅ Навыки Git и командной строки
- ✅ Базовые навыки Bash скриптинга
- ✅ Понимание встраиваемых систем и embedded-архитектуры
- ✅ Опыт совместной разработки в команде

## 📖 README для учеников

Если ты новичок и хочешь начать с основ, вот краткая дорожная карта:

1. **Создай репозиторий в Codespaces** — мы предоставляем готовое окружение
2. **Выполни первую задачу** — навигация по файловой системе (задача 1)
3. **Пройди Git-воркшоп** — инициализация, ветки, коммиты (задача 5)
4. **Напиши свой первый скрипт** — автоматизация с помощью Bash (задача 4)
5. **Работай с мониторингом** — `df`, `top`, `ps` (задача 3)

Каждый шаг имеет четкую цель и проверку. Учитель будет следить за прогрессом и давать обратную связь.
