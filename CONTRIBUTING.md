# Contributing / Вклад / Хайрлах

## Ways to contribute / Способы участвовать

### 1. Report a bug / Сообщить о баге
1. Проверь existing issues
2. Создай issue с описанием, шагами, скриншотом
3. Укажи платформу и версию

### 2. Propose an idea / Предложить идею
1. Создай issue с меткой `idea`
2. Опиши: что, зачем, кому поможет
3. Обсудим в чате

### 3. Code / Код
1. Fork репо
2. Ветка: `feature/name` или `fix/description`
3. Commit: `Add: описание`
4. PR с описанием что изменено

### 4. Documentation / Документация
- Исправь опечатку → создай PR
- Переведи на UZ/EN/HY → PR
- Добавь пример → PR

### 5. Hardware / Железо
- Схемы, прошивки, фото → PR в `hardware-lab/`
- Описание проекта → README

## Guidelines / Правила
- Код на английском (комментарии на RU/UZ)
- Тестируй перед PR
- Не пиши секреты в коде
- Small PRs > big PRs

## First contribution? / Первый вклад?
Напиши в чат: свой username, поможем с первым PR.
