Расмий **Hackerspace Tashkent** жамоасига хуш келибсиз — технология, электроника ва open-source соҳасида билим, лойиҳалар ва тадбирлар билан алмашиш майдони.

## 📌 Биз ҳақимизда

Биз Тошкент ва Ўзбекистондан келган мухлислар жамоасимиз, қуйидагилар билан шуғулланамиз:

- 🔧 **Қурилмалар яратимиз** — Arduino, ESP32, Raspberry Pi, FPGA, embedded тизимлар
- 💻 **Код ёзамиз** — web, мобил иловалар, desktop, DevOps
- 🤖 **Тажриба ўтказамиз** — робототехника, IoT, AI/ML, компьютер кўриш
- 📚 **Тажриба алмашамиз** — workshopлар, meetupлар, ҳакатонлар, қўшма лойиҳалар

## 🎯 Нима билан шуғулланамиз

- **Workshopлар ва meetupлар** — мунтазам онлайн ва офлайн учрашувлар
- **Қўшма лойиҳалар** — ғоядан прототип ва релизгача
- **Менторлик** — янги бошловчиларга ёрдам
- **Open-source** — код, схемалар, ҳужжатларни нашр этиш
- **Hardware lab** — қурилмалар, сенсорлар, платалар билан ишлаш

## 🚀 Қандай қўшилиш мумкин

1. **Ушбу репозиторийни кузатиб боринг (Watch)** — янгиланишлардан хабардор бўлиш учун
2. **Ташкилотга қўшилинг** — Telegram ёки email орқали ёзинг
3. **Мунозараларда иштирок этинг** — [Discussions](https://github.com/Hackerspace-Tashkent/hackerspace-tashkent/discussions)
4. **Лойиҳа таклиф қилинг** — идея билан Issue ёки PR яратинг
5. **Учрашувларга келинг** — эълонлар Telegram каналида

## 🛠 Қандай ўрганамиз (амалиёт + назария)

Биз браузерда тўғридан-тўғри ҳамкорлик қилиш учун **GitHub Codespaces** дан фойдаланамиз — ҳеч қандай ўрнатиш, ҳеч қандай локал созламалар йўқ. Ўқитувчилар қўнғироқлар ўтказади, Codespaces web интерфейси орқали файлларни кўриб чиқади ва талаба прогрессини кузатиб боради.

### Ўқитиш тузилиши (60% амалиёт, 40% назария)

| Тур | Фоиз | Тавсиф |
|-----|------|--------|
| **Амалиёт** | 60% | Codespacesда амалий вазифалар: пакетларни ўрнатиш, скриптинг, Git, мониторинг |
| **Назария** | 40% | Ҳар бир вазифадан олдин “нега” тушунтириш |

### Асосий амалий вазифалар

- **Файл тизимида ҳаракатланиш** — рухсатномалар, rwx, эгалик
- **Пакетларни ўрнатиш** — apt/yum, асосий пакет менежери
- **Тизим мониторинги** — `df`, `top`, `ps`, ресурсларни диагностика қилиш
- **Bash скриптинг** — автоматлаштириш, `#!/bin/bash`, бажариладиган файллар
- **Git workflow** — init, branchлар, commitлар, push
- *(Ихтиёрий)* **Docker** — иловаларни изоляция қилиш учун контейнерлар

### Иштирокдан кейин нима оласиз

- ✅ Linux муҳитида ишлашда ишонч
- ✅ Git ва буйруқлар қатори кўникмалари
- ✅ Bash скриптинг асослари
- ✅ Embedded тизимлар ва embedded архитектура тушунчаси
- ✅ Жамоада биргаликда ишлаб чиқиш тажрибаси

Агар сиз янги бошловчи бўлсангиз ва асослардан бошламоқчи бўлсангиз, қисқа йўл харитаси:
