## 📌 Биз ҳақимизда

**Биз энди бошладик.** Ҳали иштирокчимиз йўқ, бирорта учрашув бўлмаган,
тугалланган қурилма лойиҳаси йўқ. Ҳеч қандай тирик одам ҳали ўқув
материалларини охиригача ўтмаган.

Буни очиқ айтамиз, чунки йўқ нарсани ваъда қилиш уни тан олишдан ёмонроқ:
одамлар келади, тайёр бўлмаган нарсага тегишади ва қайтиб келмайди.

Ҳали мавжуд ва текширилган:

- 📚 **Ўқув материаллари** — 8 лаборатория, 67 автоматик текширув, 4 тил
- 💻 **Браузер муҳити** — Codespaces, ўрнатиш шарт эмас
- 📖 **Ҳужжатлар** — жумладан хавфсизлик қўлланмаси ва жамоат стандартлари

Батафсил ва ҳалол версия — [docs/positioning.en.md](docs/positioning.en.md).
- 💻 **Код ёзамиз** — web, мобил иловалар, desktop, DevOps
- 🤖 **Тажриба ўтказамиз** — робототехника, IoT, AI/ML, компьютер кўриш
- 📚 **Тажриба алмашамиз** — workshopлар, meetupлар, ҳакатонлар, қўшма лойиҳалар

## 🛠 Қандай ўрганамиз (амалиёт + назария)

Биз браузерда тўғридан-тўғри ҳамкорлик қилиш учун **GitHub Codespaces** дан фойдаланамиз — ҳеч қандай ўрнатиш, ҳеч қандай локал созламалар йўқ. Ўқитувчилар қўнғироқлар ўтказади, Codespaces web интерфейси орқали файлларни кўриб чиқади ва талаба прогрессини кузатиб боради.


### Асосий амалий вазифалар

- **Файл тизимида ҳаракатланиш** — рухсатномалар, rwx, эгалик
- **Пакетларни ўрнатиш** — apt/yum, асосий пакет менежери
- **Тизим мониторинги** — `df`, `top`, `ps`, ресурсларни диагностика қилиш
- **Bash скриптинг** — автоматлаштириш, `#!/bin/bash`, бажариладиган файллар
- **Git workflow** — init, branchлар, commitлар, push
- *(Ихтиёрий)* **Docker** — иловаларни изоляция қилиш учун контейнерлар

### Иштирокдан кейин нима оласиз

- ✅ Linux муҳитида ишлашда ишонч
- ✅ Git ва буйруқлар қатори кўникмалари
- ✅ Bash скриптинг асослари
- ✅ Embedded тизимлар ва embedded архитектура тушунчаси
- ✅ Жамоада биргаликда ишлаб чиқиш тажрибаси
